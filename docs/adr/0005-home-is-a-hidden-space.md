# Home 是一个隐形 space

Home 是全局一个、放在本机的真实 space，在 Spaces、新建菜单和 Inbox 的范围筛选里都不显示；`ctrl-1…9` 和切换 space 的键改由 `t3-tabs` 处理并跳过它，项目序号不变。它是真实位置，所以焦点离开 agent，所有跳转也都能自然离开 Home。识别只靠 `shared("t3-home.space")` 里的 id，不看里面有什么：默认页可能已被关掉，窗格就是用户的插槽。跳转逻辑放在 `t3-tabs`，因为标签栏一直显示，而品牌栏会随侧栏隐藏。

## Considered Options

- **`stack` 叠加页**：不占 space，但焦点仍在被盖住的窗格上，每个作用于当前窗格的键和每条跳转路径都要额外处理，漏一处就可能改到看不见的终端。

## Consequences

- 切到其他布局或执行 `herdr-app ls` 时能看到它；从另一台机器看，它是一个普通的远程 space。
- 不自建插槽机制。设置页只能选空 Home 放默认页还是终端（见 [0009](0009-settings-hold-real-preferences.md)），其他摆放没有图形化入口；摆放保存在 tab 状态里，不能作为配置迁移。切换设置时，只在 Home 只有一个窗格、且它是默认页或停在提示符的终端时替换，其余都算用户的。
- 默认页带框、居中放三个按钮、不放水印：去掉边框时 Home 像窗口塌掉了一块；房子图标、Herdr 图标和羊的剪影做水印都不好看。
