# Herdr T3 guide

Each part in more detail than the [README](../../README.md).

## Features

- **Two sidebars**: `cmd-shift-l` switches Inbox (attention) and Lists (spaces). `cmd-]` / `cmd-[` walk either mode. Settle and Snooze hiding agents belong to Inbox; Lists closes back to the previous tab.
  - Spaces: repo, branch and ahead/behind only when they're unusual; worktrees folded under their repo, checkout open or not; grouped by machine once there's more than one, and `ctrl-1…9` and the next-space keys follow the list as drawn.
  - Agents: grouped by space or by priority, pins, sub-agents nested under their parent.
  - Inbox: T3-style Settle. Agents that need you stay up top as cards, with those waiting on you first. Put finished agents away in **Settled** and they'll come back on new work. Busy agents fold into Working. Snooze hides an agent that doesn't need you until a time you pick. Use **Clean up** to end settled agents' processes.
- **One name everywhere**: Inbox cards, the agents list, tabs and pane headers name a terminal the same way: its Pi session while Pi runs in it, then a tab you named when it is the tab's only top-level agent, then a telling terminal title, else the program. When two or more top-level agents share a named tab, agents with telling titles show their own titles while unnamed peers (such as Pi without a session) keep the tab name. Sub-agents never inherit a tab name. Lazygit started where Pi was reads as lazygit, not the old session.
- **The same status marks everywhere**: a dashed circle while working, `!` when blocked or its turn failed, a dot when done. A settled or snoozed agent's done dot leaves everywhere, in Lists too; only Inbox hides a snoozed agent that's working, elsewhere it still shows as working. While Inbox shows, the tabs show no marks at all: what needs you is the sidebar's to say.
- **Slim tabs, framed panes**: 24px tabs, as T3's panel tabs, the same in the tab bar and the space panel: hovering one puts × over its icon, its status mark stays at the right end, a middle-click closes it and a name cut short shows in full on hover; rounded panes with a 28px header (name, folder, status; split, zoom and close on hover); split, the headers of the panes you're not in dim, as T3's. With Inbox, an agent you've put away says so there: a check when settled, the clock and the time left when snoozed. The header's status is its own agent's; beside it, the sub-agent button shows how many it started, all the way down, tinted when any need you, with the working mark before the count while any is at work, its tooltip saying how many need you and how many are working. It opens them in tree order, each with its program icon, its name and the mark an Agents row uses: working time, Needs you, Failed in red, a dot for a done you haven't seen, or idle time. The pointer or Up/Down lights a row; click or Enter peeks it. Right-click opens the same agent menu as the sidebar, including Send back and Copy address; Escape closes. This is how Inbox reaches a sub-agent. Zoom a split tab and the tab bar shows its panes, a segment each: click one to zoom it instead; the pane header's zoom button or `cmd-shift-enter` shows them all again.
- **The tab bar with Inbox**: about the agent you're looking at, the card Inbox lights. At the left its space (click it to open a menu with New tab `⌘T` and all agents with nested sub-agents, status marks, non-agent programs and shells in the current space; right-click a row for its agent or pane menu, or close it with the `×` that appears as you point at it, or `ctrl-d`, and the menu stays open), its parent if it's a sub-agent, and its name; the name or `⌄` opens the agent's menu: Pin, Settle, Snooze and Mark unread, as on its card, and Rename (or Rename tab when sharing a tab with another top-level agent) for top-level agents not named by Pi's session. Right-clicking the name or the parent opens that agent's menu, as in T3; right-clicking the space opens the space's menu. Only the agent you're looking at: another agent in the same tab is reached by its card, or its pane. At the right, apart: its sub-agents' tabs, then the tabs with no agent. With a program in focus the agent stays, unlit; in a tool's tab you went to from the bar it dims, and a click goes back. Once you open a new tab, whichever way, there's only the space, until you look at an agent again. In that agent's pane, shown alone, the header leaves out the name the bar already says.
- **New** opens from the sidebar's New tab in… button in either Inbox or Lists. Pick an open space to start a tab there, or pick a remembered project below the open spaces to reopen it in its original folder and on its original machine. New remembers the project after its last terminal closes. The tab bar's `+`, New tab in the Inbox breadcrumb's space menu, and `cmd-t` open a terminal tab in the current space. At Home, or with no space open, `cmd-t` opens New. The sidebar's New space asks which machine when there is more than one. `cmd-n` uses the current space's machine directly. Start agents in the terminal.
- **Home**: settling or snoozing the agent in view lands on one quiet place, not the next card, so what to look at next stays yours. Its buttons, or `cmd-]`, `cmd-p` and `cmd-t`, say what's next; Undo brings the agent back. Rather go on to the next card, or have Home be a terminal or another mod? See Settings below. `cmd-shift-h`, or Herdr's logo at the sidebar's top left, goes there anytime. It takes no number among your spaces. It's one thing alone, its page, a terminal or a mod, with no pane header: nothing to split or close, and an agent never stays there. A page or mod at Home fills everything right of the sidebar, up to the window's top: the wallpaper's picture runs under the top row too. A terminal Home keeps its frame, under a top row that folds away while the sidebar is shown.
- **Go to** (`cmd-p`): a row for every pane, agents and programs alike, named and marked as its pane header is (a tab's name counts only if you gave it), so typing `lazygit` lands on its pane, beside an agent or not, in any space. The panes you were in lately come first, newest first, however you got there, so `cmd-p`, Enter goes back to where you just were; the pane you're in comes last. Typing, a pane whose name matches comes before one matched by its folder or space.
- **Clean up** (`cmd-shift-r` / `ctrl-alt-r`, or the trash can in the sidebar's footer) reclaims what's finished without leaving Inbox. **Idle**: settled agents and shells waiting at their prompt outside the tab you're on, one block saying how many and which spaces close with them; open it to see their names by space, and **Close** ends them all. **Left behind**: programs still running in a space where no agent is at work any more, such as the `bun dev` from a finished project. Each is a card with its space and process: click it to go there, or its **Stop** (or `ctrl-d` on it) to stop it on the spot, with no second question. Programs in a space where an agent is still working, or in the space you're in, are in use and don't show. The counts follow as things close, and closing rechecks each terminal first. With nothing to clean up, a notice says so. A space you close stays in New. To reach any other terminal, use Go to: typing a space's name lists its panes.
- **Details and Actions**: the square-menu button or `cmd-shift-b` opens Details, a popup that never resizes terminals. The button or Escape closes it; changing space, tab or terminal closes it with a note.
  - The machine it works on: hover the folder icon for the folder, right-click the row to copy its path.
  - **Open in**: the main half opens the folder in Finder or the installed T3 editor last picked (Cursor, Trae, Kiro, VS Code/Insiders/VSCodium, Zed, Antigravity or JetBrains); the arrow only picks which, shared with Files. An uninstalled one falls back to Finder; on a remote space it says why it's off.
  - **Actions** (global): Add action when there are none, else the last one run and a menu of the rest, with Edit on hover. Editing keeps Details behind the dialog. A cut-off name shows whole on hover.
  - **Review**: the main half shows Review; its end names the range Review shows. The arrow lists the ranges with their counts (`3 commits`, `1 file`), the one shown checked, and Commits opens beside them with a search. Picking one shows Review on it. It needs the Review extra and a local space.
  - From the keyboard: opened with `cmd-shift-b` (or Enter on its button), its first control is ringed. ↑ and ↓ move between rows, ← and → between a row's two halves, Enter presses; a menu opened that way has its first row lit and, once closed, gives the keyboard back to its arrow. Escape closes Details and returns to your terminal.
  - Right-click the card to show or hide these, or Reset; with all hidden, Choose what to show brings them back.
  - Opening the panel puts Details away; with the panel maximized, the shortcut brings the terminals back first. Home has no Actions.
- **Other machines**: spaces group by machine once there is more than one, and Inbox cards from elsewhere carry a remote-machine mark with no separate tooltip. Lists' Agents rows show the machine's name only in their hover details. Hover an Inbox card to see its machine's name too. Add a machine from Herdr's Settings; a rebuilt one offers Connect, and New space asks which machine.
- A warning beside a machine's name means its agents stop when you disconnect, even if it is connected now. Click it for Herdr's instructions and Copy button; run the suggested command yourself on that machine. Reporting needs remote herdr-core 0.1.21 or newer; older cores without the field show no warning.
- **Program icons**: Inbox, Agents, tabs, pane headers, Go to and sub-agent menus use Herdr's official artwork, including its original whitespace and colors. Icon slots follow each component's size.
- **Space marks**: a space shows its repo's favicon, found on its own machine, else a monogram in one of T3's colors.
- **Right-click menus**: right-click anything that stands for an agent, a space, a repo, a machine, a tab or a pane for its menu, the same wherever you right-click it. An agent's (its Inbox card, its Agents row, its name in the tab bar): Pin, Settle, Snooze or Wake, and Mark unread (with Inbox only, shown or hidden; Snooze's times open beside the menu as you rest on it, as T3's submenus; Mark unread appears for an idle agent that has finished a turn, puts it back to Done in place on its Inbox card, pane header and space menu as well as Agents and tabs in Lists, and clears Settled or Snoozed), Rename (or Rename tab when sharing a tab with another top-level agent) for top-level agents not named by Pi's session, Copy address, Send back to its parent, Close pane. A space's (its row in Spaces or Agents, the tab bar, the Inbox's filter): New tab, Rename, Copy path, New and Open worktree, Remove worktree, Close. A repo's dim row in Spaces: Open, Copy path. A machine's heading: New space here, Connect. A tab's: New tab, Rename, Close. A pane's (its terminal, its header): Split, Zoom pane or Unzoom pane, Copy address, Send right-clicks to pane, Close pane. What can't be done right now isn't listed.
- **Closing asks first**: a tab's or pane's ×, a tab's middle-click, `cmd-w`, `cmd-shift-w` and the right-click menus' Close confirm while a program is running in it, and close at once when none is. If another terminal joins the tab or the space would now close too, you get a fresh confirmation.
- **The space panel**: the rightmost panel belongs to the space across terminal tabs. Each space keeps its tabs, active tab, visibility and maximize state; width is shared window-wide. First open is empty: Open a surface offers Files F and, with the extra installed, Review R; + has the same choices. Review reads the repository where the tab works: its last terminal's folder, else the space's, so a space whose folder isn't a repository still reviews the repository you `cd`'d into. On another machine or outside a repository it's greyed with the reason. + Files adds or picks a generic full-width tree. A file replaces that generic tab in place, or picks its own tab if it has one; other files append. All file tabs share one tree; picking a tab clears the search and shows the file. Review is unique. The head has the tabs, + right after the last one, maximize/restore and the panel toggle; platform controls appear only at the window's right. Each tab's icon becomes × on hover or keyboard focus. Too many tabs scroll with the wheel, and ‹ › appear together after them, each greyed when there's nothing more that way; the active tab scrolls into view. Two files with the same name look the same, as in T3; a name cut short shows in full on hover. At the top right, Details, Lists' + and the panel toggle form one group whose right edge sits over the pane header's last control; the panel head's first tab and last button line up with the header of the Files or Review tab below. Hide (`cmd-alt-b`) keeps tabs and exits maximize. ×, middle-click or `cmd-w` in Files or Review closes the active tab, never the terminal behind it; the right neighbour becomes active, else the left, and the last one hides the panel; reopened, it's empty. Tab menu: Copy path, Close, Close others, Close to the right, Close all. `cmd-t` in Files or Review opens + under it; F / R add, arrows and Enter work; in a terminal `cmd-t` is still a new tab. Switching keeps Review's range, group, file and position; closing Review and adding it again starts from its default. Each space keeps only the three most recently shown file previews/Editors/positions; older file tabs reload from the top. Each surface keeps full data for three recent spaces. Hidden views stop refreshing and catch up on return, with no recursive watchers (Files normally 5s local, 10s remote; Review 15s).
- **Files**: the current space's folder, local or remote, read-only. Generic Files is a full-width tree; a file opens its content on the left and the tree on the right. A folder's icon opens and closes with it, files have their type icons, and a loaded single-folder chain stays on one row (`a / b`) even when folded; Review's tree looks the same. Ignored entries dim; change badges belong to Review, not Files. Search files finds paths in unopened folders and keeps the results in their directory tree; past 200 matches it keeps those whose file name matches and the shorter paths. Words it hasn't searched yet show as loading, never with other words' results. Opening a result keeps the search; selecting another file tab clears it and reveals that file. Escape clears the input and leaves it. Refresh and Expand/Collapse all sit beside the padded search field, whose ring shows focus. Collapse stops an earlier expansion from reopening folders. Arrow keys, Home/End and Enter/Space work in the tree, one row selected at a time. A file shown from a tab or a command doesn't take the keyboard from your terminal; a click in the tree, a breadcrumb or Locate does. Directory breadcrumbs open beside the original file and retain its return trail; a chevron shows that folder's contents in one menu, as T3's: a folder in it takes the menu's place, **Back** on top (or ←) returns to the folder above, Escape closes it, and picking a file opens it. The header's Open in shares the editor preference and its menu with Details: choosing an editor remembers it, the primary button opens it. Preview/Code, word wrap and the tree toggle keep their places across modes; unavailable controls stay disabled and explain why. Markdown defaults to Preview; code and images remain readable. Right-click or Shift+F10 opens a menu (`cmd-w` closes it, not the tab) with local Open, Reveal and Open with, relative Copy path, and Insert into this tab's last active terminal (disabled if absent). Insert never presses Enter and safely restores text clipboard without replacing images or a later copy. Drag the tree's left edge, or focus it and use ←/→ or Home/End, to resize; its width and wrap choice are independent of Review. Text refreshes while visible; reselect images to reload them. Directory breadcrumb hover brightens text without filling a background; keyboard focus keeps its ring. Breadcrumbs and tree rows have no hover tooltip, even when truncated; the split arrow keeps only its accessibility label. Drag any file or folder row into a terminal to paste its path, quoted by Herdr and never sent with Enter. Local files can be copied to a remote terminal; folders cannot be uploaded. A remote path can only be dropped into a terminal on its own machine. Control-character paths are rejected; dropping outside a terminal cancels. Insert into terminal remains a separate menu action.
- **Review** (optional, [see Extras](extras.md#pullsreview)): the panel's Review tab reviews the repository where the tab works; add it from + or press `cmd-shift-g`. Each space keeps its own review, and the panel shows the current space's. Under the toolbar the groups are one row of tabs, as pulls.review's: each shows its icon, name, a mark when it needs care, lines added and removed, how many files, and a ring for how much of it you've reviewed. Pick one and the diff on the left and the file tree on the right show that group alone, its summary heading the diff once AI has analyzed it. Before AI analyzes the diff the groups are the folder ones (Docs, Code…); with a single group there's no list. The tree lists folders before files at each level, with names in natural order ignoring case; the diff and `j`/`k` follow the same order. Its folders are folded to start except down to the file you're reading, the group's subgroups as rows in it; the file you're reading is the one row lit, following the diff as you scroll. Each row starts with its reviewed box, then the same icons as Files'. Drag file or folder rows into terminals as in Files, or right-click for the same Open, Reveal, Open with, Copy path and Insert menu. Right-click does not change the current file, folder folds or reviewed boxes; its row stays lit while the menu is open. Deleted files cannot drag and offer only Copy path; subgroup rows have neither action. The tab bar shows no counts; the scope menu below has them. Analysis status is shown on the Review tab beside pulls.review's logo. The scope button at the left of Review's header, as T3 Code's diff panel has it, says what you're reviewing (Changes, Uncommitted, Outgoing, Incoming or a commit) and opens a menu to pick another: those four with their counts, then Commits, a searchable submenu beside it. On Changes, the base after `head →` is a button, as T3's: pick another branch to compare against, local or remote (a row's switch takes its remote), or Automatic for the default branch. Each space keeps its pick, and Commits then lists what's past it. A space on another machine has no Review.

## Everyday use

In Inbox, type a name in **Search**. Matching agents appear in a compact list in the sidebar. Use ↑ or ↓ to pick a result, Enter to open it and Esc to clear the search. `cmd-p` opens Go to across the window. **Filter by space** lists spaces with Inbox entries and keeps any space you've already selected in the filter. When the filter leaves the Inbox empty, **Show all spaces** restores the full scope.

Click a card to open the agent. Click its pin to unpin it. Undo restores its place. Hover the worktree icon beside a branch to see the checkout directory name and branch.

When you return from Home or jump between spaces, the destination terminal appears below its tab bar. If you left Files open there, it appears alongside the terminal. Selecting a cached file tab brings back its breadcrumb and preview together.

If the list changes while a menu is open, your click or Enter still applies to the command and target you selected. When that target disappears, choose again. This also applies when you close and reopen a file tab with the same path. In standalone Inbox, Settle uses the agent in focus when you press the shortcut.

Insert refuses paths containing control characters; use Copy path instead.

- **Sidebar**: `cmd-shift-l`, or Sidebar shows in Settings, switches Lists and Inbox; while the sidebar is hidden only Settings does, as T3's sidebar keys do nothing then. The button past the window buttons hides it, or `cmd-b`; hidden, the same button stays where it was to bring it back, alone, as in T3: go Home with `cmd-shift-h`. While it's hidden the layout says nothing of how the agents are doing, at Home or anywhere: Herdr's own notice still tells you when one needs you, and showing the sidebar shows them all. `cmd-shift-b` opens Details.
- **Buttons that open a menu**: Details, the panel's `+`, the sub-agent count, sort, New space, New tab in… and the rest stay pressed while their menu or popup is open, with no tooltip over it; press one again to close it.
- **Inbox**: hover a finished card and click `✓ Settle` to put it away; new work brings it back, or click the undo arrow on its row. `cmd-shift-s`, with the sidebar hidden too (not in Lists), settles the agent in view and lands on Home, or brings it back if it is settled. An agent you bring back yourself, with the undo arrow, a drag out of Settled or `cmd-shift-s`, goes on top of Active. `Undo` puts it back where it was. `cmd-]` then opens the top card, so you can work down them one at a time. Drag a card or row, as in T3: move it 6px to lift it; the `Pinned` and `Active` labels open, the lifted row says what letting go will do (Pin, Unpin, Settle, Un-settle) and the list opens a gap where it will land. Pinned keeps your order, a new pin on top; Active and Settled keep their own. Esc or leaving the sidebar sideways puts it back; leaving off the top or bottom lands it where the badge says; Working cards don't lift. Press a card's `✓ Settle` (or a settled row's undo) and move across rows to settle (or bring back) the whole run. The agents list shares these pins.
- **Settings**: the sliders button in the sidebar's footer, or `cmd-shift-,`, opens the layout's own settings, laid out as Herdr's. Changes apply at once and survive updates.
  - **After putting away**: Home (the default), or Next card: settling, snoozing, dragging or sweeping away the agent in view opens the next card, and Home once none is left. Closing an agent's tab still goes to Home.
  - **Home shows**: Default, the page with its three buttons; Terminal, a shell in your home folder; or a mod of your own. A mod is offered once its `mod.json` in `~/.config/herdr-app/mods` says `"home": true`. Home swaps at once. Start an agent in Home's terminal and that space becomes an ordinary one, named for its folder, right where you are; the next time you go Home you get a new Home.
  - **Sidebar shows** (on the Sidebar page): Inbox or Lists, the same switch as `cmd-shift-l`.
- **Focus ring** (off by default): in `~/.config/herdr-app/layouts/herdr-t3.json`, set the pane's `focus.color` from `"background"` to `"accent"` (or any theme color) to ring the focused pane. It applies on save.
- **Snooze**: hover a card (working ones too, not one that needs you), click the clock and pick a time. It waits on the Snoozed shelf and wakes where it was, marked `Woke` until you look at it with Inbox selected, or click that. It shows meanwhile while it needs you; a failed turn, new work you give it in view (in Lists too), a pin or Settle ends the snooze. `Undo` takes it back for 5 seconds; on the shelf, hover a row for the crossed-out alarm clock (press and move across rows to wake the run), or drag it out.

## Keys

The layout's bindings live in the `layout:herdr-t3` section of `keys.json` and are merged on install. The table includes the supplied alternatives, such as `ctrl-alt-r` for Clean up. On Linux and Windows, you can also bind Herdr's native keys to the commands below in your own `keys.json` to use the layout's close confirmations and space numbering.

| Key | Command | Does |
| --- | --- | --- |
| `cmd-shift-b` | `t3-tabs.details` | Toggle Details |
| `cmd-b` | `t3-tabs.toggle-sidebar` | Hides or shows the sidebar, as its buttons do. In this layout it replaces Herdr's `layout.toggle:sidebar` |
| `cmd-shift-l` | `t3-tabs.sidebar` | Switches the sidebar between Lists and Inbox; nothing while it is hidden. In this layout it replaces Herdr's `layout.switch` |
| `cmd-shift-s` | `t3-tabs.settle` | Settles the agent in view and goes to Home, or brings it back if it's settled. With Inbox selected, shown or hidden; in Lists it does nothing. A busy agent stays, a pinned one loses its pin |
| `cmd-shift-z` | `t3-tabs.undo` | Undo, while the Undo notice offers it |
| `cmd-shift-h` | `t3-tabs.home` | Goes to Home |
| `cmd-shift-,` | `t3-tabs.settings` | Opens the layout's settings |
| `cmd-alt-b` | `t3-tabs.panel` | Shows the space panel on the page last shown, or hides it |
| `cmd-shift-g` | `t3-tabs.review` | Opens the panel on Review, or closes it if it's already showing Review. Only with the Review extra |
| `cmd-shift-e` | `t3-tabs.files` | Opens the panel on Files, or closes it if it's already showing Files |
| `cmd-w`, `ctrl-alt-shift-x` in Files or Review | `t3-files.close`, `review.close` | Close the active panel tab, not the terminal |
| `cmd-t` in Files or Review | `t3-chrome.surface-menu` | Open + under it; F / R add Files / Review |
| `cmd-t`, `ctrl-alt-c` with terminal focus | `t3-tabs.new` | New terminal tab |
| `ctrl-1…9`, `ctrl-alt-shift-1…9` | `t3-tabs.space:<n>` | Your nth space, not counting Home |
| `cmd-alt-]` / `cmd-alt-[`, `ctrl-alt-shift-]` / `ctrl-alt-shift-[` | `t3-tabs.space-next` / `t3-tabs.space-prev` | The next or previous space, going around Home |
| `cmd-1…9`, `ctrl-alt-1…9` | `t3-tabs.tab:<n>` | The nth tab the bar shows |
| `cmd-shift-]` / `cmd-shift-[`, `ctrl-tab` / `ctrl-shift-tab`, `ctrl-alt-]` / `ctrl-alt-[` | `t3-tabs.tab-next` / `t3-tabs.tab-prev` | The next or previous tab the bar shows |
| `cmd-p` | `mod.open:t3-picker` | Go to any pane by its name or program, or back |
| `cmd-shift-r` / `ctrl-alt-r` | `t3-tabs.cleanup` | Clean up: close idle terminals, stop programs left behind |
| `cmd-]` / `cmd-[` | `t3-tabs.next` / `t3-tabs.prev` | The next or previous top-level agent, in the selected sidebar's order, stopping at either end, shown or hidden. Inbox walks the rows it draws (a folded shelf only its row in view); Lists walks folded groups too |
| `cmd-w`, `ctrl-alt-shift-x` | `t3-tabs.close-tab` | Closes the tab, asking first if a program is running in it |
| `cmd-shift-w`, `ctrl-alt-x` | `t3-tabs.close-pane` | Closes the pane, asking first if a program is running in it |

With a dialog or popup open (Go to, New, a menu, Settings, the command palette, the Actions editor and the like), these close-tab and close-pane keys close it instead, as in Herdr's own layout (the `mod:…` sections of `keys.json`).

In Files and Review, `cmd-shift-w` and `ctrl-alt-x` dismiss the current menu. To close a terminal pane with either key, focus the terminal first.

Otherwise tabs, spaces and panes keep Herdr's own keys. Use the mouse to pin and drag in Inbox.

By keyboard: move onto a sidebar list with Herdr's `pane.go` and Tab walks every control in the window, the panel's button included, with Enter or Space doing what a click does. In New and Go to, Tab also reaches the footer's buttons (New space, `← Spaces`, New tab in…).

## Update

The updater checks that the layout and key bindings each contain one JSON object and that each required mod has an entry file. If you save either configuration during the copy, it reports the conflict and keeps your edit. Finish saving, then rerun the updater. Its message tells you which files were already updated.

Only one update runs per app home. If an interrupted update leaves `.herdr-t3-update.lock`, wait for its updater and `rsync` processes to exit, remove the empty lock directory with `rmdir`, then retry.

Herdr doesn't update mods or layouts from others, and adding this again would install a renamed second copy (`t3-inbox-2`), since an install never overwrites. Update by overwriting instead:

```sh
git clone --depth 1 https://github.com/JinJieBeWater/herdr-t3 && herdr-t3/scripts/update.sh
```

Or tell your Herdr agent: "Update Herdr T3: clone github.com/JinJieBeWater/herdr-t3, run its `scripts/update.sh`, then run `herdr-app check` on each `mods/t3-*`." Mods reload by themselves on save; no restart. It needs `jq` and `rsync`, and stops before changing anything if one is missing or your `keys.json` or layout isn't valid JSON.

- It overwrites `mods/t3-*` and `layouts/herdr-t3.*`, deleting files that are gone, and the Review and theme-export extras and the extra themes you've installed. Extras you haven't are left out.
- It merges `keys.json`: the repo's keys go into your `layout:herdr-t3` section and the popups' `mod:…` sections, replacing the same key, and it prints each one it replaced so a remap can go back. Your other keys and sections stay. It also prints keys of yours that aren't in the repo: an old one (`"cmd-shift-a": "t3-tabs.view"`, say) can be deleted.
- Kept: pins, folds, sort, the layout's settings, the Settled shelf, settled agents, projects remembered by New, and your actions. From the installed layout: the theme, the sidebar you were on, the focus ring color, the panel's Review slot and the settings of any Review bar or theme-export block whose extra is still installed. Uninstalling an extra removes its blocks on the next update.
- Lost: your other edits to the overwritten files; make those again. Going on to the next card after a Settle is a setting now, not an edit.
- If the first install renamed something because of a clash, the script doesn't know: it installs the original names, so point the layout back at your copy or delete it.
- What changed, and what some keys now do: the [changelog](../../CHANGELOG.md).

## Known limits

- Home is a space of its own: switch to another layout, run `herdr-app ls` or look from another machine, and it shows as one.
- Rename Home and another window on the same Herdr core won't know it: it makes a second Home.
- On a space on another machine, Review is greyed in the panel, and a Review bar you've added shows nothing.
- Files on another machine: text changes usually show up within 10 seconds while visible (slower for expensive reads); select an image again to reload it. Images over 512 KB aren't previewed.
- Files previews text up to 1 MB, and colors only common languages (JavaScript and TypeScript, JSON, YAML, Rust, Go, Python, shell, CSS, C and C++, Java, Kotlin, Ruby, PHP, SQL, Lua, GraphQL, Makefiles); TOML, HTML, Swift and others show plain. While an agent rewrites a file over 16 KB you're looking at, or after you switch Wrap on one, it shows plain for a moment and takes its colours once it has stopped changing for about 10 s (0.3 s after a Wrap switch); if you scroll meanwhile, it stays plain until you open it again. Over 256 KB it stays plain unless you press **Highlight anyway** above the code, and colouring it holds the window for a moment.
- Files shows code in Herdr's native read-only editor, so its line-number gutter can't match T3's background and height. You can still select text.
- Wrapped long lines (the default, in Files and Review) break at the panel's edge, in Review mid-word if need be, though never inside an accented letter or a joined emoji.
- Files searches paths only, not contents, and leaves out what Git ignores; outside Git it covers at most 200,000 files.
- Until the Inbox has shown once since Herdr started, it doesn't keep its card order while the sidebar is hidden, so `cmd-]` and `cmd-[` may walk an old order. `cmd-shift-s` settles as usual.

Clicking a path in a terminal doesn't open it: Herdr doesn't tell the layout about clicks in a terminal.
