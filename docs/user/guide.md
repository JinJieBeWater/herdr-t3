# Herdr T3 guide

English · [中文](guide.zh-CN.md)

Each part in more detail than the [README](../../README.md).

## Features

- **Two sidebars, one key apart** (`cmd-shift-b`): Inbox organizes by attention and Lists by project; `cmd-]` and `cmd-[` walk either one. Settle, Snooze hiding a working agent, and landing on Home when the agent in view is closed are Inbox's; in Lists, closing it goes back to the tab you were on before. The tab bar differs too.
  - Spaces: repo, branch and ahead/behind only when they're unusual; worktrees folded under their repo, checkout open or not; grouped by machine once there's more than one, and `ctrl-1…9` and the next-space keys follow the list as drawn.
  - Agents: grouped by space or by priority, pins, sub-agents nested under their parent.
  - Inbox: T3-style Settle. Agents that need you stay up top as cards, one waiting on you first; finished ones are settled by hand into a quiet list and come back on new work. Busy agents fold into a Working shelf. Snooze hides any agent that doesn't need you until a time you pick.
- **One name everywhere**: Inbox cards, the agents list, tabs and pane headers name a terminal the same way: its Pi session while Pi runs in it, then a tab you named, then a telling terminal title, else the program. Two Pis in one tab read as their own sessions; lazygit started where Pi was reads as lazygit, not the old session.
- **The same status marks everywhere**: a spinner while working, `!` when blocked or its turn failed, a dot when done. A settled or snoozed agent's done dot leaves everywhere, in Lists too; only Inbox hides a snoozed agent that's working, elsewhere it still spins. While Inbox shows, the tabs show no marks at all: what needs you is the sidebar's to say.
- **Slim tabs, framed panes**: 24px tabs, as T3's panel tabs; rounded panes with a 28px header (name, folder, status; split, zoom and close on hover); split, the headers of the panes you're not in dim, as T3's. With Inbox, an agent you've put away says so there: a check when settled, the clock and the time left when snoozed. An agent with sub-agents shows how many there, or how many need you; click it to list just this agent's sub-agents, one line each: its program icon, name, how long it has been working or what it waits on, and at the right its own status, marked as in Agents; nested ones indented. Hover one for its details, and pick one to peek it. This is how Inbox reaches a sub-agent. Zoom a split tab and the tab bar shows its panes, a segment each: click one to zoom it instead; the pane header's zoom button or `cmd-shift-enter` shows them all again.
- **The tab bar with Inbox**: about the agent you're looking at, the card Inbox lights. At the left its space, its parent if it's a sub-agent, and its name; click the space for an empty tab there, the one already waiting or else a new one, in place of `+`; the name or `⌄` opens the agent's menu: Pin, Snooze and Settle, as on its card, and Rename when it's alone in its tab. Right-clicking the name or the parent opens that agent's menu, as in T3; right-clicking the space opens the space's menu. Only the agent you're looking at: another agent in the same tab is reached by its card, or its pane. At the right, apart: its sub-agents' tabs, then the tabs with no agent. With a program in focus the agent stays, unlit; in a tool's tab you went to from the bar it dims, and a click goes back. Once you start something new, from the space at the left or with `cmd-t`, there's only the space, until you look at an agent again. In that agent's pane, shown alone, the header leaves out the name the bar already says.
- **New**: the tab bar's `+` opens a terminal tab in the current space (with Inbox, the space at the bar's left does that, going to an empty tab already there first); the sidebar's New tab, in Lists and Inbox alike, picks a space first. Its New space asks which machine once there is more than one; `cmd-n` doesn't ask and uses the current space's machine. No agent picker: start agents in the terminal.
- **Home**: settling or snoozing the agent in view lands on one quiet place, not the next card, so what to look at next stays yours. Its buttons, or `cmd-]`, `cmd-p` and `cmd-t`, say what's next; Undo brings the agent back. Rather go on to the next card, or have Home be a terminal or another mod? See Settings below. `cmd-shift-h` or Herdr's logo at the sidebar's top left goes there anytime. It takes no number among your spaces. It's one thing alone, its page, a terminal or a mod, with no pane header: nothing to split or close, and an agent never stays there. With the sidebar shown, the empty tab bar folds away and Home fills the height.
- **Go to** (`cmd-p`, or Inbox's Search): a row for every pane, agents and programs alike, named and marked as its pane header is (a tab's name counts only if you gave it), so typing `lazygit` lands on its pane, beside an agent or not, in any space. The panes you were in lately come first, newest first, however you got there, so `cmd-p`, Enter goes back to where you just were; the pane you're in comes last. Typing, a pane whose name matches comes before one matched by its folder or space.
- **Actions**, as T3 Code's run button: at the tab bar's top right, `▶` runs the action you ran last, `▾` lists them all (click one to run it), with a gear to edit each and Add action. Each action is a command run in a new tab, or split right/down, in the focused terminal's folder or its own. Edited in the app, not in a file. It is the `t3-actions` mod, installed with the layout and also published [on its own](https://github.com/JinJieBeWater/herdr-t3-actions) for other layouts.
- **Other machines**: spaces group by machine once there is more than one, and Inbox cards from elsewhere carry a server mark with no separate tooltip. Lists' Agents rows show the machine's name only in their hover details. Hover an Inbox card to see its machine's name too. Add a machine from Herdr's Settings; a rebuilt one offers Connect, and New space asks which machine.
- **Program icons**: Inbox, Agents, tabs, pane headers, Go to and sub-agent menus use Herdr's official artwork, including its original whitespace and colors. Icon slots follow each component's size.
- **Project icons**: a space shows its repo's favicon, found on its own machine, else a monogram in one of T3's colors.
- **Right-click menus**: right-click anything that stands for an agent, a space, a repo, a machine, a tab or a pane for its menu, the same wherever you right-click it. An agent's (its Inbox card, its Agents row, its name in the tab bar): Pin, Settle and Snooze or Wake (with Inbox only; Snooze's times open beside the menu as you rest on it, as T3's submenus), Rename when it's alone in its tab, Copy address, Send back to its parent, Close. A space's (its row in Spaces or Agents, the tab bar, the Inbox's filter): New tab, Rename, Copy path, New and Open worktree, Remove worktree, Close. A repo's dim row in Spaces: Open, Copy path. A machine's heading: New space here, Connect. A tab's: New tab, Rename, Close. A pane's (its terminal, its header): Split, Zoom, Copy address, Send right-clicks to pane, Close pane. What can't be done right now isn't listed.
- **Closing asks first**: a tab's or pane's ×, `cmd-w`, `cmd-shift-w` and the right-click menus' Close confirm while a program is running in it, and close at once when none is.
- **The space panel**: a panel at the window's right, as tall as the sidebar, with Files and, with the Review extra, Review as its pages; one shows at a time. It stays as you switch tabs and shows the current space; each space keeps it open or closed, on its page, wide or not, as T3 keeps one per thread, and a space you haven't opened it in has it closed. The button at the tab bar's right end, the sidebar's toggle mirrored, opens it on the page you left it on and closes it (with the Review extra, it's the Review bar's last part); the keys are T3's: `cmd-alt-b` does what that button does, and with the keyboard in the panel `cmd-w` closes it; `cmd-shift-g` opens it on Review, or closes it when it's already there. Its top row has the pages, `⤢` to widen it over the tabs and back, and `×` to close it. Drag its edge to resize it; it starts as wide as the tabs.
- **Files**: the current space's folder, on this computer or another machine, read-only. The tree on the right, the same as Review's, opens folders as you go (a folder holding just one folder shows as one row, `a / b`), dims what Git ignores, and marks changed files A, M, D or R in Review's colors; a closed folder with changes inside gets a dot. Pick a file to read it on the left: code with syntax colors, Markdown as a preview (or its code; the last choice stays), and images. Search files, at the top of the tree's column, finds any file by its path, even in folders you haven't opened: type a few words, each must appear in the path; ↑/↓, Enter and Esc work there. In the tree, ↑/↓ move, ← and → close and open folders, and Enter opens a file. Click a folder in the path above the file to find it in the tree. A changed file has an Open in Review button in the toolbar. Right-click a row to copy its path or relative path, mention it in the space's agent (typed into its prompt, without Enter), reveal it in Finder or open it in its default app (the last two on this computer only), or open a change in Review. It updates by itself when files change. Files and Review are laid out alike: a toolbar across the top, the content on the left, and the file tree in a column on the right, the same width on both pages; drag its left edge to widen it, or close it with the tree button at the toolbar's right end (each page remembers). The button beside the search collapses or expands every folder.
- **Review** (optional, [see Extras](extras.md#pullsreview)): a bar in the tab row counts what there is to review in the focused worktree, and a click opens that review on the panel's Review page. Each space keeps its own review, and the page shows the current space's. Under the toolbar the groups are one row of tabs, as pulls.review's: each shows its icon, name, a mark when it needs care, lines added and removed, how many files, and a ring for how much of it you've reviewed. Pick one and the diff on the left and the file tree on the right show that group alone, its summary heading the diff. Before AI analyzes the diff the groups are the folder ones (Docs, Code…); with a single group there's no list. The tree is the same as Files', its folders folded to start, the group's subgroups as rows in it; the file you're reading is the one row lit, following the diff as you scroll. Opening a file in another group from elsewhere shows that group and goes to the file. Each row starts with its reviewed box. Right-click a file or folder for the same menu as in Files, with Open in Files and Mark reviewed; the toolbar's Open in Files button opens the file you're reading in Files. The bar's counts are quiet, dim until you hover one or until it's the diff the page shows, and the panel's button comes last, on its own, so it stays put as counts come and go. While the panel is closed the analysis shows as a small badge on that button, with the layout's marks; while it's open, on the panel's Review tab, which wears pulls.review's logo. The scope button at the left of the Review page's header, as T3 Code's diff panel has it, says what you're reviewing (Changes, Uncommitted, Outgoing, Incoming or a commit) and opens a menu to pick another: those four with their counts, then Commits, a searchable submenu beside it. On Changes, the base after `head →` is a button, as T3's: pick another branch to compare against, local or remote (a row's switch takes its remote), or Automatic for the default branch. Each space keeps its pick, and Commits then lists what's past it. A space on another machine has no Review.

## Everyday use

- **Sidebar**: the button at the top right of the sidebar (or `cmd-shift-b`) switches between Lists and Inbox; the one next to it hides the sidebar.
- **Inbox**: hover a finished card and click `✓ Settle` to put it away; new work brings it back, or click the undo arrow on its row. `cmd-shift-s`, with the sidebar hidden too (not in Lists), settles the agent in view and lands on Home, or brings it back if it is settled. An agent you bring back yourself, with the undo arrow, a drag out of Settled or `cmd-shift-s`, goes on top of Active. `Undo` puts it back where it was. `cmd-]` then opens the top card, so you can work down them one at a time. Drag a card or row, as in T3: move it 6px to lift it; the `Pinned` and `Active` labels open, the lifted row says what letting go will do (Pin, Unpin, Settle, Un-settle) and the list opens a gap where it will land. Pinned keeps your order, a new pin on top; Active and Settled keep their own. Esc or leaving the sidebar sideways puts it back; leaving off the top or bottom lands it where the badge says; Working cards don't lift. Press a card's `✓ Settle` (or a settled row's undo) and move across rows to settle (or bring back) the whole run. The agents list shares these pins.
- **Settings**: the sliders button in the sidebar's footer, or `cmd-shift-,`, opens the layout's own settings, laid out as Herdr's. Changes apply at once and survive updates.
  - **After putting away**: Home (the default), or Next card: settling, snoozing, dragging or sweeping away the agent in view opens the next card, and Home once none is left. Closing an agent's tab still goes to Home.
  - **Home shows**: Default, the page with its three buttons; Terminal, a shell in your home folder; or a mod of your own. A mod is offered once its `mod.json` in `~/.config/herdr-app/mods` says `"home": true`. Home swaps at once. Start an agent in Home's terminal and that space becomes an ordinary one, named for its folder, right where you are; the next time you go Home you get a new Home.
- **Focus ring** (off by default): in `~/.config/herdr-app/layouts/herdr-t3.json`, set the pane's `focus.color` from `"background"` to `"accent"` (or any theme color) to ring the focused pane. It applies on save.
- **Snooze**: hover a card (working ones too, not one that needs you), click the clock and pick a time. It waits on the Snoozed shelf and wakes where it was, marked `Woke` until you look at it or click that. It shows meanwhile while it needs you; a failed turn, new work you give it in view (in Lists too), a pin or Settle ends the snooze. `Undo` takes it back for 5 seconds; on the shelf, hover a row for the crossed-out alarm clock (press and move across rows to wake the run), or drag it out.

## Keys

The layout's own, in the `layout:herdr-t3` section of `keys.json` (an install merges them). They cover macOS's keys only: `keys.json` can't bind a key by platform, so on Linux and Windows Herdr's own keys (`ctrl-shift-w` closing a tab, `alt-1…` picking a space and the rest) still run Herdr's commands, skipping the layout's rules such as asking before a close and leaving Home out of the count. Bind them to the commands below in your own `keys.json`.

| Key | Command | Does |
| --- | --- | --- |
| `cmd-shift-b` | `t3-tabs.sidebar` | Switches the sidebar between Lists and Inbox |
| `cmd-shift-s` | `t3-tabs.settle` | Settles the agent in view and goes to Home, or brings it back if it's settled. With Inbox selected, shown or hidden; in Lists it does nothing. A busy agent stays, a pinned one loses its pin |
| `cmd-shift-h` | `t3-tabs.home` | Goes to Home |
| `cmd-shift-,` | `t3-tabs.settings` | Opens the layout's settings |
| `cmd-alt-b` | `t3-tabs.panel` | Shows the space panel on the page last shown, or hides it |
| `cmd-shift-g` | `t3-tabs.review` | Opens the panel on Review, or closes it if it's already showing Review. Only with the Review extra |
| `cmd-w`, `ctrl-alt-shift-x`, with the keyboard in the panel | `t3-files.close`, `review.close` | Closes the panel, not the tab behind it |
| `cmd-t`, `ctrl-alt-c` | `t3-tabs.new` | A new tab here; at Home, New, which picks the space first |
| `ctrl-1…9`, `ctrl-alt-shift-1…9` | `t3-tabs.space:<n>` | Your nth space, not counting Home |
| `cmd-alt-]` / `cmd-alt-[`, `ctrl-alt-shift-]` / `ctrl-alt-shift-[` | `t3-tabs.space-next` / `t3-tabs.space-prev` | The next or previous space, going around Home |
| `cmd-1…9`, `ctrl-alt-1…9` | `t3-tabs.tab:<n>` | The nth tab the bar shows |
| `cmd-shift-]` / `cmd-shift-[`, `ctrl-tab` / `ctrl-shift-tab`, `ctrl-alt-]` / `ctrl-alt-[` | `t3-tabs.tab-next` / `t3-tabs.tab-prev` | The next or previous tab the bar shows |
| `cmd-p` | `mod.open:t3-picker` | Go to any pane by its name or program, or back (the same as Inbox's Search) |
| `cmd-]` / `cmd-[` | `t3-tabs.next` / `t3-tabs.prev` | The next or previous top-level agent, in the selected sidebar's order, stopping at either end, shown or hidden. Inbox walks the rows it draws (a folded shelf only its row in view); Lists walks folded groups too |
| `cmd-w`, `ctrl-alt-shift-x` | `t3-tabs.close-tab` | Closes the tab, asking first if a program is running in it |
| `cmd-shift-w`, `ctrl-alt-x` | `t3-tabs.close-pane` | Closes the pane, asking first if a program is running in it |

With a dialog or popup open (Go to, New, a menu, Settings, the command palette, the Actions editor and the like), these close-tab and close-pane keys close it instead, as in Herdr's own layout (the `mod:…` sections of `keys.json`).

Otherwise tabs, spaces and panes keep Herdr's own keys. Pinning and dragging in Inbox are by mouse; Clear takes the keyboard as other buttons do.

By keyboard: move onto a sidebar list with Herdr's `pane.go` and Tab walks every control in the window, the panel's button included, with Enter or Space doing what a click does. In New and Go to, Tab also reaches the footer's buttons (New space, `← Spaces`, New tab).

## Update

Herdr doesn't update mods or layouts from others, and adding this again would install a renamed second copy (`t3-inbox-2`), since an install never overwrites. Update by overwriting instead:

```sh
git clone --depth 1 https://github.com/JinJieBeWater/herdr-t3 && herdr-t3/scripts/update.sh
```

Or tell your Herdr agent: "Update Herdr T3: clone github.com/JinJieBeWater/herdr-t3, run its `scripts/update.sh`, then run `herdr-app check` on each `mods/t3-*`." Mods reload by themselves on save; no restart. It needs `jq` and `rsync`, and stops before changing anything if one is missing or your `keys.json` or layout isn't valid JSON.

- It overwrites `mods/t3-*` and `layouts/herdr-t3.*`, deleting files that are gone, and the Review and theme-export extras and the extra themes you've installed. Extras you haven't are left out.
- It merges `keys.json`: the repo's keys go into your `layout:herdr-t3` section and the popups' `mod:…` sections, replacing the same key, and it prints each one it replaced so a remap can go back. Your other keys and sections stay. It also prints keys of yours that aren't in the repo: an old one (`"cmd-shift-a": "t3-tabs.view"`, say) can be deleted.
- Kept: pins, folds, sort, the layout's settings, the Settled shelf and settled agents, which live in `data/`, `shared.json` and terminal labels, and your actions. From the installed layout: the theme, the sidebar you were on, the focus ring color, the panel's Review page and the Review bar and theme-export blocks.
- Lost: your other edits to the overwritten files; make those again. Going on to the next card after a Settle is a setting now, not an edit.
- If the first install renamed something because of a clash, the script doesn't know: it installs the original names, so point the layout back at your copy or delete it.
- What changed, and what some keys now do: the [changelog](../../CHANGELOG.md). From before Focus became Inbox (`t3-focus` → `t3-inbox`), first rename `data/t3-focus` to `data/t3-inbox` (the cards' order and shelves) and delete `mods/t3-focus`.

## Known limits

- Home is a space of its own: switch to another layout, run `herdr-app ls` or look from another machine, and it shows as one.
- Rename Home and another window on the same Herdr core won't know it: it makes a second Home.
- A space on another machine has no Review bar and no Review page.
- Files on another machine: changes show up within 10 seconds, and images over 512 KB aren't previewed.
- Files previews text up to 1 MB, and colors only common languages (JavaScript and TypeScript, JSON, YAML, Rust, Go, Python, shell, CSS, C and C++, Java, Kotlin, Ruby, PHP, SQL, Lua, GraphQL, Makefiles); TOML, HTML, Swift and others show plain.
- Wrapped long lines (the default, in Files and Review) break at the panel's edge, in Review mid-word if need be, though never inside an accented letter or a joined emoji.
- Files searches paths only, not contents, and leaves out what Git ignores; outside Git it covers at most 200,000 files.
- While `⤢` widens the panel over the tab bar, `cmd-alt-b` and `cmd-shift-g` do nothing: close the panel with its `×` or `cmd-w` in it, or narrow it with `⤢`.
- Until the Inbox has shown once since Herdr started, it doesn't keep its card order while the sidebar is hidden, so `cmd-]` and `cmd-[` may walk an old order. `cmd-shift-s` settles as usual.
