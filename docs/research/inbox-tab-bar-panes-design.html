③ 一个 tab 里有同级的 agent（分屏）

同一个 tab 的顶层 agent 是同级的，各有一张 Inbox 卡片。面包屑的标题位就放同级切换器：高亮的是焦点所在的 agent，也就是侧栏亮着的那张卡片。点另一个 agent 的窗格、点它的卡片、点切换器里的它，三者结果相同：焦点、卡片高亮和切换器高亮一起移过去。各项位置不动，只有高亮移动。只有一个 agent 时就是普通标题。

各处的点击

位置点击来自
space 名在这个 space 新建标签（t3-tabs.new）T3：New thread in project
父 agentfocusAgent 回父级T3：parent thread
标题 ⌄当前 agent 的菜单（改名、关闭…）；双击改名T3：thread actions menu
切换器里的同级 agentfocusAgent：焦点、卡片、高亮一起移；zoom 中则移动 zoom和点它的卡片、窗格相同
⧉还原分屏（只在 zoom 时出现）Herdr 原生 zoom
变暗的标题回到这个 agent本布局：程序 tab 属于 space
虚线框里的程序把 zoom 移过去（focusPane）Herdr 原生 zoom
其余胶囊tab.select；可拖动排序、×、右键菜单同现在T3：panel tabs

窄宽度

先缩面包屑：父级成 …，space 名最多 160px 后截断；切换器里当前的保留名字，其余同级只剩图标（悬停显示全名）；胶囊按现有规则让位，再不够滚动。
