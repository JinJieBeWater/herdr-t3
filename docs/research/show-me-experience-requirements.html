WORK PACKAGE A

详情只保留三行

内容必须做到边界
机器／目录真实机器名、完整路径提示与复制；复用 space 菜单机器是事实，不迁移终端
Open in本机用系统文件管理器；多个可用目标才有下拉远程路径不交给本机 Finder
Actions现有运行／下拉／新增／编辑／删除；完整动作名称保留执行位置、cwd、数据和删除确认

布局与键盘

  • 详情全宽度默认收起，只在点击时弹出。
  • 面板开关稳定在窗口右上角，放大／恢复在它旁边。
  • ⌘⇧B 详情，⌘⌥B 面板，⌘⇧G Review。
  • Inbox／Lists 用现有侧栏按钮。

执行与焦点

  • 打开时记录来源，popup 焦点不改变执行目标。
  • 来源失效时关闭并提示重新打开。
  • Escape 先关子菜单，再关详情。
  • 外点关详情；正常外点保留工具面板。
验收核心：打开详情前后终端几何一致；Actions 的真实目录和运行位置正确；关闭 popup 不误关终端。

SHARED CONSTRAINTS

切换页面，不改变另一页的阅读状态

Files · 工作目录

本机和远程只读浏览、路径搜索、代码／Markdown／图片预览。文件树在右，目录自然排序；每页自己的导航宽度与换行选择。

文本 ≤ 1 MiB；远程图片 ≤ 512 KiB。首版保持文件浏览，不加入编辑和文件管理。

Review · 所选变更

范围选择在顶栏；组是整页一行标签。选组时 diff 和树共同筛选，子组在树里。保留 AI 分组、说明、已看进度和阅读键位。

只读；不加入批注交给 agent、GitHub PR 评审或 Git 写操作。

两页共用外框、树行、菜单与状态组件；各自保留文件、位置和偏好。取消隐式跨页跳转。只在可见时轮询，显示时补读；递归 watcher 不作为前置依赖。详细资源与刷新边界见交接稿第 4 节。
