# Home 壁纸：固定 Dots 与导入构图实施计划

状态：待实施。本文件记录计划；本轮不修改实现、安装配置或已有壁纸。

## 目标与交互

用户已明确：删除 Braille / Blocks / Dots 三选一，新图片固定第三种 Dots；位置和铺放方式只在导入时调整，Apply 后固定下来。

本计划建议首版提供两种铺放方式：**填满**（cover，默认）和**完整显示**（contain），配合拖动定位、缩放和重置。缩放为相对所选铺放方式的 1–4 倍；完整显示在 1 倍时保留整张图，继续放大允许裁切。

```text
选择图片 → 自动生成 Dots → 构图预览 → Apply → 固定显示
选择 Studio .ans → 保留字符画法 → 构图预览 → Apply → 固定显示
```

预览卡片用“填满 / 完整显示”、原生缩放条和“重置”替代原来的风格选择。Home 画布可直接拖动；键盘能调整位置和缩放。Apply 后这些编辑控件消失，日常保留原有换画、添加和删除入口。

内置画及已保存壁纸维持现状；本次不提供保存后重新编辑。直接复制 .ans 到壁纸文件夹仍按默认构图载入，这个后备入口不自动弹出导入预览。

## 构图计算与保存

构图数据使用一个新共享键 `asciicn-wallpaper.placements`，按 `file:<名字>` 保存：

```json
{
  "file:Coast": { "mode": "cover", "zoom": 1.4, "x": 0.7, "y": 0.5 }
}
```

- `x/y` 为 0–1 的相对对齐位置；`zoom` 是相对铺放基准的倍率。读取时验证模式与数值，限制位置和缩放范围。
- cover 基准取窗口与图像比例的较大值；contain 取较小值，再乘 zoom。最终坐标为 `(窗口宽 - 图片宽) × x`、`(窗口高 - 图片高) × y`。
- 同一计算供预览和保存后显示使用。拖动只改变位置，缩放只改变图块的显示尺寸；两者都不重新生成 .ans 或 SVG 文件。
- 保存相对参数，不保存屏幕像素坐标。重启、缓存重建、窗口缩放或侧栏开合后按相同规则重新计算。窗口比例变化会改变裁切量，“固定”指构图参数固定，不是锁定旧窗口的像素截图。
- 草稿构图留在内存。持久构图独立于 `.tiles/scene.json`，缓存重建不会把它丢掉；无需保留原图供保存后编辑。
- 无构图记录时沿用现有铺满、`scene.focus` 横向对齐和纵向居中；已有 .ans 不重写、不重新转风格。删除或确认源文件已消失时清掉对应构图记录。

## 导入与提交顺序

1. 先更新行为文档及存储约定，再写会失败的行为用例。
2. 图片读取、缩放和解码后只生成一次 Dots；选择框导入 .ans 则直接读取字符画。两条路径都先建立临时场景，尚不发布新 .ans 或改变当前选择。
3. 拖动、铺放方式、缩放及重置仅更新草稿。复用原生 Slider、现有按钮和焦点 helper，保持 T3 的尺寸、主题色和键盘可达性；离开画布或结束操作时释放拖动状态。
4. Apply 沿用现有分块、原子发布且不覆盖目标的保存方式，准备最终缓存；就绪后写入该图构图，再选中，最后清理预览。去掉 `refresh/convertOwned` 提前选中的 `picking` 分支，由发起 Apply 的实例完成提交。
5. Apply 失败保留草稿及其构图，当前壁纸保持原选择；重试沿用已发布且内容核对一致的文件。Cancel 丢弃草稿，不写持久构图；失败 Apply 已发布的 .ans 按现有规则保留。
6. 图片取消、连续选图、导入取消和 View 关闭都用草稿身份使迟到结果失效。只保留仍用于异步生命周期的状态，移除风格切换专用版本与像素缓存。

## 验收与交付

- 新图片直接显示 Dots，界面和输出均无旧风格选择；现有 Studio/Braille .ans 仍能正常绘制。
- 横图、竖图、方图在 cover / contain 下保持比例；可定位与缩放；拖动边界、重置、键盘操作正确，拖动不会触发文件重写。
- Apply 后构图与预览一致；重开 Home、重启窗口、换主题、调整窗口及侧栏后，构图参数仍有效；日常画面不能拖动编辑。
- Cancel 不改变选择或已保存构图；原子保存冲突、缓存失败后的重试、两 Home 并行、转换中删除等既有场景继续通过。
- 三份壁纸检查先跑失败再通过；随后运行 `scripts/sync.sh`、`scripts/check.sh`，最终必须输出 `all checks passed`。sync 会写本机安装和三个独立仓库，先核对其基线及差异，只提交本任务造成的变化。
- 在独立演示环境以默认侧栏宽度检查完整窗口：Dots 预览、两种铺放、拖动/缩放、Apply 后固定、Cancel 和失败恢复均有证据。拖动须做真实指针验收，不能只用方法调用代替；采用隔离桌面，不占用用户当前桌面。
- 收尾检查删除项、文档与代码一致性，按 Conventional Commits 提交本任务文件；push 由用户发起。清理自建演示窗口、进程与临时文件。

首版范围不含平铺、拉伸、旋转、保存后编辑及历史壁纸批量转换。当前“长时间离开 Home 后闪空白”的历史问题另行诊断，不计入本次构图改动。
