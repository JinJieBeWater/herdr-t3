2 Review 的 base 选择器 报告有误，已修正建议小改

报告说 T3「按名字排」，这一点说错了。T3 的服务端（GitVcsDriverCore.ts:2570,2725）是先放当前分支，再放默认分支，其余按最近提交时间排，时间相同再按名字。本地 readRefs 也是按最近提交排，所以真正的差别只有一点：默认分支没有固定在顶上。main 好几天没提交的话，会被挤到下面去。

5 Agents 列表默认 Priority 属实建议保持

t3-agents/main.js:20：agents.sort 没设过时用 Priority。README 写的是「Lists 按项目排」，但这一点 Spaces 列表已经做到了。agents.sort 和 Herdr 自带的 agents 列表共用，它的默认也是 Priority。

建议保持顺序，只把 README 改准确些：「Spaces 按项目排，Agents 默认按紧急程度排，也可以按 space 分组」。这处只改文案。
