# Home

状态：已实施。行为说明以 [RECIPE.zh-CN.md](../RECIPE.zh-CN.md) 的 Home 一节为准；本文保留决策和取舍。

## 目标

收起当前查看的 agent 后，提供一个固定、可预期的落脚点，不再把用户带到下一张卡片，也不把刚处理完的内容留在屏幕上。

## 用户的判断

- 自动跳到下一张，等于替用户决定下一步看什么。
- 留在原处也不对：Settle 的意思是“这个我已经不想再看了”。
- 需要的是一个固定、预期中的占位窗口；它也可以承载用户自定义的内容。
- Home 不应该因为是 space，就占掉项目序号或出现在切换路径里。

## 已确定

### 行为

- **收起：** 收起正在查看的 agent（Settle、Snooze、拖动、划选）后总是回 Home，Review 例外，见[行为模型](layout-model.md)；收起后台 agent 不跳转。
- **继续处理：** 在 Home 点按钮或按 `cmd-]` 打开最上面的卡片，两者走同一个命令。侧栏隐藏时，模式继续生效，见 [行为模型](layout-model.md)。在 Home 按 `cmd-shift-s` 不会误收任何 agent。
- **Undo：** 如果还在 Home，恢复状态并带回那个 agent；如果已去别处，只恢复状态，不跳转。
- **入口：** 品牌栏按钮和 `cmd-shift-h`，在 Home 时按钮点亮。再按一次留在 Home，不是开关。
- **新建：** 在 Home 按 `cmd-t` 或 `ctrl-alt-c` 先选 space，再新建，工作不会进入 Home。
- **关闭：** `cmd-w` 在 Home 不起作用；单个窗格能正常关闭，关掉最后一个后回到默认页，这也是重置方式。
- **标签栏：** 在 Home 留空，不显示 tab、`+`、Actions 和 Review。位置由品牌栏按钮和窗格标题 Home 表示。
- **默认内容：** 和其他窗格一样带框，标题栏不写名字；居中显示三个按钮（`⌘]` Next agent、`⌘P` Go to、`⌘T` New tab），不显示卡片名字和数量；Next agent 没有可去之处时变暗。
- **外观的来由：** 参考 VSCodium 的空窗口。试过去掉边框融入窗口，结果 Home 像窗口塌掉了一块，和其他页面不是同一个应用，所以保留原有结构。房子图标、Herdr 官方图标和羊的剪影都试过水印，用户都觉得不好看，所以不放水印。
- **启动：** 回到上次的位置，和现在一样。

### 结构

- **形式：** 隐形 space，全局一个，放在本机；远程 agent 被收起后也回本机 Home。它是真实位置，所以焦点离开 agent，所有跳转也都能自然离开 Home。
- **隐藏：** `t3-spaces`、`t3-new-menu`、Inbox 的范围筛选都不显示 Home。Go to 保留用户放进 Home 的窗格。
- **导航：** `ctrl-1…9`、`ctrl-alt-shift-1…9` 和两组切换 space 的键在 `layout:herdr-t3` 中改由 `t3-tabs` 处理并跳过 Home，共 22 个绑定。项目序号不变。
- **自定义：** 窗格就是插槽。用户通过命令或 agent 放入任意 mod 或终端程序。第一版不做“添加”菜单和小组件系统。
- **单独发布的 Inbox：** 通过 prop 启用 Home。`herdr-t3-inbox` 不传这个 prop，保持现在的跳转行为。

### 实现要点

- 跳转逻辑放在 `t3-tabs`：`<mod>.<command>` 只送达显示中的 mod，标签栏一直显示，而品牌栏会随侧栏隐藏，Home 里的默认页也可能已被关掉。
- 懒创建：第一次需要时依次执行 `space.new`、`tab.new {mod}`，再关闭初始终端。`run` 不返回 id，`spaces()` 也要在命令后一帧左右才更新，所以每一步都等上一步生效。
- 用 `shared` 记录 space id，不靠里面的 mod 识别 Home，否则用户关掉默认页后就认不出来了。默认内容只在创建时放入，之后不再动用户的摆放。

## 取舍

- 连续处理多按一次键，换来跳转结果固定、不被下一张卡片打断。这是对 T3 行为的有意偏离，要写进 RECIPE。
- 不选 `stack` 叠加页：不占 space，但焦点仍在被盖住的窗格上，每个作用于当前窗格的键和每条跳转路径都要额外处理。漏一处就可能改到看不见的终端。
- 隐形 space 的残余问题：切到其他布局或执行 `herdr-app ls` 时能看到它；从另一台机器看时，它是一个普通的远程 space。
- 同一 core 的另一个窗口不知道 Home 的 id（`shared` 不共享），靠名字认领。名字是 `Home` 加零宽空格，而不是 `t3-home` 这类可见的保留名：Go to 和 Inbox 会显示 space 名。不用“叫 Home 且有 `t3-home` 窗格”：默认页可能被关掉，用户的 space 也可能有这个窗格。认错会藏起用户的 space，认不出最多多一个 Home，所以只取严格匹配。
- 不自建插槽机制，因此没有图形化添加入口；摆放结果保存在 tab 状态里，不能作为配置文件迁移。
- dashboard 不内置。以后可以作为普通 mod 放进 Home。

## 验证

已在 `scripts/demo/stage.sh` 的隔离环境回放：Settle 落到 Home；Undo 带回；再按 Settle 不误收；`cmd-]` 对应的命令打开最上面的卡片；序号和切换跳过 Home；`cmd-w` 不起作用；关掉最后一个窗格回到默认页；新建先选 space；重启后保留。

命令通过 `herdr-app do` 触发，物理按键还要在真实窗口确认一次。
